# Contributing

Thanks for your interest in Remote Desktop Commander!

This repository contains the public manifests, documentation, and issue tracker for the hosted service at `mcp.desktopcommander.app`. The service implementation is not open source, so code contributions aren't possible here — but you can still help:

- **Report bugs or request features** via [GitHub Issues](https://github.com/desktop-commander/remote-desktop-commander/issues)
- **Improve the docs** — pull requests fixing errors or clarifying setup instructions in this repository are welcome
- **Contribute to the open-source local server** at [wonderwhy-er/DesktopCommanderMCP](https://github.com/wonderwhy-er/DesktopCommanderMCP), which also contains the device agent used for pairing
- **Join the community** on [Discord](https://discord.gg/kQ27sNnZr7)

For security issues, please follow [SECURITY.md](SECURITY.md) — do not open public issues.
